# code
Earth-observation-based analysis reveals shifting forest-area and biomass-density contributions to long-term forest AGB gains on the Loess Plateau, China

Reproducibility package for a 1990–2023 assessment of forest aboveground biomass on China’s Loess Plateau. Includes portable Python workflows, derived data, model outputs, source data, and figure scripts for stock decomposition, process-specific spatial modelling, and robustness analyses.
